# 🏬 LojaFacilCoreV2

**LojaFacilCoreV2** é um sistema de gerenciamento de vendas e controle de estoque desenvolvido em **ASP.NET Core MVC**, com persistência de dados via **Entity Framework Core** e banco de dados **SQL Server**.  
O projeto foi criado com foco acadêmico, servindo como aplicação prática para estudos de engenharia de software e bancos de dados relacionais.

---

##  Tecnologias Utilizadas

- **Linguagem:** C# (.NET 8.0)  
- **Framework:** ASP.NET Core MVC  
- **ORM:** Entity Framework Core  
- **Banco de Dados:** SQL Server  
- **Front-end:** HTML, CSS, JavaScript, Bootstrap  
- **Controle de Versão:** Git & GitHub  
- **IDE:** Visual Studio 2022  

---

##  Funcionalidades Principais

-**Gestão de Produtos:** cadastro, atualização e exclusão de produtos.  
-**Vendas:** controle de itens vendidos, quantidade e valor total.  
-**Usuários:** autenticação e controle de acesso (Gerente/vendedor).
-**Relatórios:** exibição de dados e histórico de vendas.  
-**Banco de Dados:** criado e gerenciado via migrações do Entity Framework Core.
